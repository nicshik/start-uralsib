## Цель

Превратить `start-uralsib.lovable.app` в редирект-заглушку, которая мгновенно переадресует любого посетителя на `https://trailway.tech/start-uralsib/` (всегда на главную, путь не сохраняем).

## Что меняем

### 1. `index.html`
В `<head>` добавляем:
- `<meta http-equiv="refresh" content="0; url=https://trailway.tech/start-uralsib/">` — мгновенный редирект даже без JS.
- `<link rel="canonical" href="https://trailway.tech/start-uralsib/">` — для поисковиков, чтобы они склеили старый домен с новым.
- `<meta name="robots" content="noindex">` — убрать старый URL из выдачи.
- Inline-скрипт `<script>location.replace('https://trailway.tech/start-uralsib/')</script>` сразу после открытия `<body>` — мгновенный редирект в браузере без ожидания загрузки React.

Заголовок и описание заменим на «Сайт переехал на trailway.tech».

### 2. `src/App.tsx`
Заменяем всё дерево роутов на одну минимальную страницу-заглушку: лого Уралсиба, текст «Сайт переехал», кнопка-ссылка `https://trailway.tech/start-uralsib/`, плюс `useEffect` с `window.location.replace(...)`. Это страховка на случай, если meta-refresh почему-то не сработает (например, SPA уже загрузился из кэша).

Это удалит всю клиентскую логику (роутер, формы, SMS, и т.д.) из публичной сборки — на старом домене она больше не нужна.

### 3. Что НЕ трогаем
- Исходники страниц (`src/pages/*`), компоненты, edge-функции, БД — всё остаётся в репозитории на случай, если захотите вернуться. Просто не используются.
- Lovable Cloud (Supabase) — оставляем, она используется новым хостингом trailway.tech (если он бьёт в тот же бэкенд).

## После применения

Нужно нажать **Publish → Update** в Lovable, чтобы редирект уехал в продакшн на `start-uralsib.lovable.app`. До публикации будет работать только в превью.

## Альтернатива (если передумаете)

Можно вместо редиректа просто **депубликовать** проект (Project Settings → Unpublish). Тогда `start-uralsib.lovable.app` начнёт отдавать 404. Это решение в один клик и не требует правки кода — но посетители старого URL не узнают, куда переехал сайт.
